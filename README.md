Reva Chalet is a high-end luxury booking platform for curated architectural sanctuaries in Jordan. Built with a focus on immersive user experience, sophisticated aesthetics, and cutting-edge AI integration.

## 🛠️ Tech Stack

- **Frontend:** Next.js 14+ (App Router)
- **Styling:** CSS Modules, Tailwind CSS
- **Animations:** Framer Motion, GSAP (Parallax)
- **Database:** Prisma, PostgreSQL
- **AI Engine:** Google Gemini API

## 🌟 Core Features

- **Immersive Parallax Hero:** High-performance, GPU-accelerated scroll effects
- **Visual Comfort:** Reduced motion support, optimized contrast, and soft shadows
- **Interactive Stats:** RAF-based smooth counting animations
- **Mobile-First Design:** Responsive drawer navigation and booking bars
- **Multilingual Support:** Full English and Arabic (RTL) integration

## Getting Started
